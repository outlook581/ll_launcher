# Windows platform integration

`DesktopIntegration` must be constructed and used on the main WPF UI thread. Call `Initialize()` once, after restoring the main window's position. `RestoreDock` accepts `left`, `right`, `top`, `bottom`, or an empty string. The root window persists its geometry and integration state when `StateChanged` fires. That event may fire more than once during a display transition, so writes should be debounced.

Tray and edge-tab clicks show and activate the main window before raising `ShowRequested`. Hovering the topmost edge tab reveals the launcher after 150 ms while leaving keyboard focus with the current application. When revealed from its folded state, the panel temporarily uses the same topmost window layer as the tab. Hiding, minimizing, pinning, or undocking the panel restores its normal window layer. Pinning locks the window's position and keeps it expanded. Explicit hide and exit commands remain available while pinned.

Leave-to-hide is a 450 ms single-shot timer and only applies while docked. The UI must set `IsInteractionActive` during context menus, editing, app-item drag-and-drop, and import operations, and clear it in `finally`. Mouse capture and visible owned windows also suppress hiding. There is no hidden-state polling; mouse events and display/work-area/DPI messages drive behavior. A 120 ms single-shot timer coalesces display/layout changes.

`ExitRequested` only requests exit: the root must allow actual closing, save its data, and dispose the integration. `BackupRequested` delegates backup UX to the root.

`ShellService.Launch` uses the Windows Shell and deliberately launches `.lnk` files themselves, preserving shortcut arguments and working directories. Imported links are snapshotted in SQLite, including the Windows security zone. The repository materializes a local copy for Shell launch and icon extraction. It propagates errors for the UI to explain. `GetIcon` resolves icons through the Shell, including `.lnk` custom icons, filesystem folders, and explicit `shell:`/`::{...}` entries. Bare executable names are resolved in the Windows and System directories, PATH, and App Paths registry entries. `IShellItemImageFactory` requests the actual 48/64/96/etc. icon before falling back to the Shell's standard large/small icon; applications that only supply small icons may still look soft when enlarged. `ms-settings:` has no filesystem icon here and returns null for the UI's Fluent fallback. Shell icons, including negative lookup results, have a 192-entry LRU cache. Call `ClearIconCache` after an explicit icon refresh.

For HTTP(S) entries, including saved `.url` shortcuts, the card shows the Shell icon while `WebsiteIconService` fetches the site's favicon. The service shares requests and caches results by origin. It starts at the site's root, so the bookmarked page path and query string stay local.

Title dragging captures the pointer on the title bar and moves the window in screen pixels. On release, the launcher docks against the work area of the monitor under the pointer. Clicking a title-bar button or resizing the window does not start a drag.

Screen geometry uses native physical-pixel rectangles and each window's DPI. Snap distance is 18 DIP. It follows each monitor's work area (excluding a normal taskbar), including shared borders between monitors. Monitor removal selects the nearest remaining monitor and clamps the main window and edge entry into its work area. A UI minimum size larger than the work area cannot be fully accommodated; its top-left corner stays reachable.

Validation limits: compilation and single-monitor checks do not establish correctness on physical mixed-DPI/multi-monitor systems. Windows 10, monitor unplug/replug, taskbars on other edges, a restarted Explorer, full-screen applications covering the tab, and actual shortcut/site associations need manual acceptance checks on the target machines. Shell icon extraction is synchronous and should not be called in bulk on every render, especially for remote/network paths. Exact working-set/CPU targets require measuring the assembled release build.
