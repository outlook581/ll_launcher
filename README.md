# 栖点

栖点是一款适用于 Windows 10 / 11 x64 的便携桌面启动器。把常用的程序、文件夹、文档和网址放进同一个窗口，按名称搜索，单击即可打开。窗口可以吸附在屏幕边缘，鼠标移过去就会展开。

## 快速开始

首次使用的电脑需要安装 **.NET 10 桌面运行时（Windows x64）**。如果尚未安装，请在微软下载页找到“.NET 桌面运行时 10.0.x”，选择 Windows 行“安装程序”下的 **x64**。每台电脑只需安装一次。[微软官方下载页](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)

1. 将便携版 ZIP 完整解压到自己有写入权限的文件夹，保留 `Qidian.exe`、`Assets/` 和 `Runtime/` 的相对位置。
2. 双击 `Qidian.exe`。首次启动使用**云瓷白**，应用列表为空，左侧有“全部”“常用”和“其他”。
3. 把一个桌面快捷方式拖进主窗口，再单击新增的卡片即可启动。鼠标移到卡片上时，点亮星标就会出现在“常用”中。
4. 添加网址时，打开右上角 **··· → 添加启动项 / 网址**，填入网址并选择分组。也可以用 **从文件选择添加…** 一次选取多个文件。

导入 `.lnk` 或 `.url` 时，栖点会在数据库里保存一份快捷方式。之后即使删掉桌面上的快捷方式，栖点仍可使用保存的副本启动。快捷方式指向的程序或文件需要继续保留在有效位置。

批量添加时，栖点会跳过目标分组中已有的路径。如果某个文件无法读取，其他文件仍会继续导入。把鼠标移到窗口底部的状态消息上，可以看到已添加的数量和首个失败原因。

## 日常使用

| 我想做什么 | 操作 |
| --- | --- |
| 搜索并启动 | 在窗口内按 `Ctrl+F` 聚焦搜索框。输入名称即可搜索所有分组，按 `Enter` 打开第一项。要选其他结果，先按 `↓` 进入结果区，再用方向键选择。 |
| 管理分组 | 左下角 **＋** 新建分组，旁边的按钮可折叠分组名称。“全部”和“常用”固定在前两位，其余分组可拖动排序。右键分组可编辑。删除自建分组后，里面的条目会移到“其他”。 |
| 移动或编辑条目 | 将卡片拖到左侧的目标分组即可归类。右键卡片也可移动、编辑或移除启动项。 |
| 切换视图和排序 | 用应用列表标题右侧的按钮切换图标或列表视图。进入具体分组并清空搜索框后，拖动条目即可排序。图标之间的竖线、列表行之间的横线表示松手后的插入位置。 |
| 贴边和固定 | 拖动标题栏到屏幕工作区任一边缘并松手。鼠标离开后窗口收成小图标，悬停即可展开。点图钉可锁定位置并保持展开，再点一次解锁。要取消贴边，选择 **··· → 解除边缘吸附**。 |
| 切换皮肤 | 在 **··· → 皮肤设置** 中选择云瓷白、深海蓝、松针绿、暮山紫或暖砂杏。选中后立即生效，下次启动会沿用。 |
| 隐藏或退出 | 点 **×** 隐藏到系统托盘，单击托盘图标可重新打开。要完全退出，请选择 **··· → 退出栖点**，或右键托盘图标选择 **退出**。 |

默认窗口为 480 × 624 个逻辑像素，随 Windows 显示缩放调整。拖动边框可以改变大小，栖点会记住窗口尺寸和位置。

## 数据、备份与升级

分组、条目、收藏、排序和窗口设置都保存在 SQLite 数据库里。默认情况下，栖点优先使用已有的 `Data/launcher.db`，否则在 `Qidian.exe` 旁打开或创建 `launcher.db`。通过 **··· → 打开数据目录** 可以找到当前使用的数据库。

要指定数据目录，可在便携版目录打开 PowerShell，运行 `.\Qidian.exe --data-dir "D:\QidianData"`。程序会打开该目录中的数据库，首次使用空目录时会创建新库。加上 `--hidden` 可以让新实例启动后隐藏到托盘。

- **备份**　选择 **··· → 立即备份**。修改条目或分组后，程序会在下一次定时检查（每 15 分钟一次）或从菜单退出时自动备份。如果上次异常退出，下次启动会补上待备份的修改。数据库旁的 `Backups/` 保留最近五份备份，包含已导入的快捷方式。
- **恢复**　如果启动时无法打开数据库，按提示从 `Backups/` 选择一份备份。程序先校验备份，再替换数据库，将原库与对应日志一起保存在 `Recovery/` 中。如果切换过程中退出，下次启动会先完成恢复。
- **升级**　从菜单完全退出栖点，将新版 ZIP 解压到空目录，这样旧版自带的运行时会留在旧目录。若原数据库在 `Data/`，将整个 `Data/` 复制到新版目录。若在旧版程序旁，复制数据库文件 `launcher.db` 及同目录下已有的 `launcher.db-*` 文件、`Backups/` 和 `Recovery/`。如果通过 `--data-dir` 使用单独的数据目录，启动新版时继续指定原数据目录的完整路径即可。已有的桌面快捷方式或启动脚本需要指向新版目录中的 `Qidian.exe`。
- **迁移**　在新电脑安装 .NET 10 桌面运行时（Windows x64），退出栖点后复制整个便携目录。如果使用了 `--data-dir`，还需复制指定的数据目录，并用新位置启动。换电脑后，若程序或文档的位置有变，可右键卡片选择 **编辑**，填入新的目标路径或新快捷方式的路径。

## 从源码运行

项目使用 C#、WPF、.NET 10 和 SQLite。在 Windows 上用安装了“.NET 桌面开发”工作负载的 Visual Studio 2026 打开 [ll_launcher.slnx](ll_launcher.slnx)，按 `F5` 即可调试。

也可以在解决方案目录用 PowerShell 构建并启动应用。

```powershell
dotnet build ll_launcher.slnx -c Release
dotnet run --project ll_launcher/ll_launcher.csproj -c Release --no-build
```

运行存储测试可验证分组和条目排序、快捷方式保存、事务回滚以及备份恢复。

```powershell
dotnet run --project tests/Launcher.Storage.Tests.csproj -c Release
```

## 发布便携版

在装有 .NET 10 SDK 或兼容新版 SDK 的 Windows 上，双击项目根目录的 [package.cmd](package.cmd)，或在 PowerShell 中运行下面的命令。首次构建需要还原 NuGet 依赖。

```powershell
.\package.cmd
```

脚本按依赖框架模式发布 Windows x64 版本，启动时使用电脑上安装的 .NET 10 桌面运行时。输出文件为 `artifacts/Qidian-<版本号>-win-x64.zip`，版本号取自项目文件。每次打包使用新的发布目录，成功后替换同版本 ZIP。将这个 ZIP 作为 GitHub Release 的附件上传。[Portable 发布配置](ll_launcher/Properties/PublishProfiles/Portable.pubxml)

| 发布内容 | 用途 |
| --- | --- |
| `Qidian.exe` | 用户双击运行的入口。资源管理器、栖点主页、系统托盘和贴边入口都使用青冈树图标。 |
| `Assets/` | 外置程序图标、界面 SVG、图标许可和五套配色的 `Skins.json`。 |
| `Runtime/` | 栖点主程序集、运行配置、SQLite 引擎及其 .NET 依赖库。`Licenses/` 收录随包组件的许可和声明。 |
| `README.md` | 桌面运行时下载入口、使用和升级说明。 |
| `LICENSE` | 栖点原创代码的 Apache-2.0 许可证。 |
| `NOTICE` | 项目版权信息、第三方组件与随包许可证的对照说明。 |
